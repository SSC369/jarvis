# Features

One folder per feature: `NNN-<feature-slug>`, three digits, zero padded, in
creation order. Slugs are lowercase kebab-case and name the feature, not the
ticket.

Each folder holds the six stage documents and an `assets/` directory for design
exports and screenshots. Copy the files from `../templates/` and drop the
`.template` from each name.

The registry of every feature and its stage is in [../index.md](../index.md).
