# Glossary

One definition per term. Docs use the term, never a synonym. If two docs need
two different meanings for one word, the word is wrong. Rename one.

Add a term the first time a doc needs it. Keep definitions to one or two
sentences.

| Term | Definition | First used in |
|---|---|---|
| Epic PRD | The stage 1 document. States the problem, users, requirements and success metrics for a feature. Contains no solution. | process |
| Build plan | The stage 3 document. Locks high-level architecture and asks the user the direction questions. Also called the HLD. | process |
| Implementation plan | The stage 4 document. File-level plan, contracts, tasks and tests. Also called the LLD. | process |
| Gate | The approval a stage needs from the user before the next stage starts. | process |
| Locked | An approved doc whose decisions cannot change without a change record. | process |
| Design system delta | A token or component added or changed by a feature's design. | process |
