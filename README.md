# Jarvis

An AI SaaS application.

The product is defined in [`process-docs/`](./process-docs). Every feature
moves through five gates, each one a document, each one approved before the next
begins:

```
0 Intake → 1 Epic PRD → 2 Design → 3 Build plan (HLD) → 4 Implementation plan (LLD) → 5 Dev
```
